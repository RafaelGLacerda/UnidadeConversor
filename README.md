# 📏 Conversor de Unidades 🌐

🌐 Acesse o aplicativo online aqui: [https://unidadeconversor.netlify.app/](https://unidadeconversor.netlify.app/)

---

## 🚀 Funcionalidades

- Conversão instantânea de qualquer unidade suportada.
- Interface limpa e responsiva.
- Suporte a múltiplos sistemas de unidades.
- Compatível com todos os dispositivos (desktop, tablet e mobile).

---

## 🧩 Tecnologias Utilizadas

- **HTML5**  
- **CSS3** (com design responsivo)  
- **JavaScript** (lógica de conversão dinâmica)
